# Alpha Channel Plugin

**Play, watch, listen and socialise together.**

## Installation

1. Open Dalamud Settings and go to **Experimental → Custom Plugin Repositories**.
2. Add the [Alpha Channel repository](https://alphachannel.pages.dev/): `https://alphachannel.pages.dev/`
3. Open the Plugin Installer with `/xlplugins`, search for **Alpha Channel**, and install it.

**Current version:** `2.2.5.3`

## Project History

Alpha Channel evolved from the original in-game TV created by Voudi in 2024.

## Attribution

Very early versions of Alpha Channel incorporated code from Browsingway, developed by Styr1x and based on BrowserHost by ackwell. That code is no longer included in the current plugin. We retain this acknowledgement to credit those projects’ historical contribution.

## AI Disclosure

Voudi created the original in-game TV screen in 2024 with assistance from Claude. The current Alpha Channel plugin was developed with assistance from ChatGPT, with careful oversight from our team. Our team made all design and framework decisions.

The original TV was used and tested for over two years before evolving into Alpha Channel. The plugin then went through a further three months of testing before its public release.
